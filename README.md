# PlanWithMe 1.0

Автономный планировщик для Android 8.0 и новее. Интерфейс на русском языке, кремово-шалфейная дневная и тёмная вечерняя темы.

## Первая версия

- Задачи: создание, редактирование, удаление, приоритет, дата, заметка, статусы 0/50/100%.
- Темы: создание, редактирование, удаление с переносом задач. Направления: личное, работа, учёба.
- Расписание: рабочие смены и занятия, время, место, разовые и еженедельные повторы, просмотр недель.
- Прогресс: календарь последних 371 дней в стиле GitHub, серия активных дней, прогресс тем.
- Поиск и фильтры, локальное сохранение, экспорт и восстановление JSON.

## Установка

Скачайте PlanWithMe.apk на Android, откройте файл и разрешите установку из используемого браузера или файлового менеджера, если Android запросит это. Минимальная версия — Android 8.0. Интернет и регистрация не требуются. Для встроенного интерфейса нужен актуальный Android System WebView. Это первая сборка с локальной подписью, не публикация Google Play.

Начните с кнопки +. Повтор расписания действует начиная с указанной даты. Пустой набор дней означает разовое событие. Редактирование или удаление повтора меняет всю серию. Ночную смену разделите на два события. Накладки событий допустимы: приложение не блокирует пересечения.

Прогресс заполняется реальными завершёнными задачами. Изменение статуса с завершённого на незавершённый убирает вклад задачи. При новом завершении учитывается текущий день. Процент темы усредняет статусы задач, общий процент считает полностью завершённые задачи. Серия продолжается, если активным был сегодня или вчера.

Данные Android хранятся в приватных SharedPreferences приложения. Браузерная версия использует localStorage и не синхронизируется с APK. Резервная копия переносит данные между ними. Экспортируйте копию перед удалением приложения, очисткой данных или переносом телефона. Восстановление заменяет текущее содержимое после подтверждения.

## Разработка

Android — Java Activity и WebView, интерфейс — HTML/CSS/JavaScript без внешних зависимостей. Все ресурсы включены в APK. INTERNET, доступ к контактам и широкие разрешения на файлы не запрашиваются. Для импорта и экспорта используется системный выбор файла. WebView разрешает только три встроенных файла виртуального локального HTTPS-адреса; сторонняя навигация и сетевые запросы блокируются.

Сборка требует JDK 17+ (javac и keytool), Android SDK Platform 35, Build Tools 35.0.0, Python 3. Gradle не требуется.

```sh
export ANDROID_BUILD_TOOLS=/path/to/android-sdk/build-tools/35.0.0
export ANDROID_PLATFORM=/path/to/android-sdk/platforms/android-35/android.jar
bash build.sh
```

Если javac недоступен, задайте ECJ_JAR — путь к Eclipse Java Compiler 3.39.0. Результат: dist/PlanWithMe.apk. Скрипт создаёт ../planwithme-signing.jks для локальной подписи (пароль android). Сохраните исходный ключ для будущих обновлений: другой ключ потребует удаления старого приложения. Исходный ключ первой сборки оставлен в рабочем окружении и не включён в исходный ZIP.

Для просмотра браузерной версии: `python3 -m http.server --directory assets 8000`.

## Проверено и ограничения

Проверяются синтаксис JavaScript, сборка Java/Dex, метаданные APK и подпись v2/v3. Поведение интерфейса проверяется Chromium. Запуск на реальном Android-устройстве не проверен.

Совместные планы, друзья, аккаунты, облачная синхронизация, фоновые уведомления, реклама и подписки из приложенного учебного документа в первую личную версию не входят. Следующий этап может добавить базу данных, повторяющиеся задачи, уведомления и синхронизацию. Документ использован как описание проекта, приоритет имеет запрос пользователя.
