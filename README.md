# PlanWithMe 1.1

Уютный личный планировщик для Android и браузера: задачи, работа и учёба, темы планов, календарь прогресса и дневник самочувствия.

[Скачать APK 1.1](releases/android/PlanWithMe-1.1.apk) · [Скачать сайт ZIP](releases/web/PlanWithMe-web-1.1.zip) · [Описание версии](docs/CHANGELOG.md)

## Две версии в одном репозитории

| Папка | Назначение |
| --- | --- |
| `web/` | Полный сайт: интерфейс, модель данных, темы, встроенные шрифты, PWA и компактный режим |
| `android/` | Android Activity, системный виджет, ресурсы и сборка APK; использует интерфейс из `web/` |
| `releases/android/` | Готовый подписанный APK версии 1.1 |
| `releases/web/` | Самостоятельный архив сайта, без Android-исходников |
| `scripts/` | Упаковка сайта и исходников |
| `tests/` | Проверки модели и браузерных сценариев |
| `docs/` | История изменений и инструкции |
| `dist/` | Совместимые со старыми ссылками APK и архив исходников текущей версии |

Интерфейс общий, чтобы исправления сайта попадали и в APK. Android-обвязка и дистрибутивы разделены. База на устройстве и ключ хранения сохранены, резервные копии 1.0 автоматически мигрируют в формат 1.1. Сайт и APK не синхронизируются автоматически: переносите данные через JSON-копию. Копия 1.1 содержит профиль и дневник; старая версия 1.0 её не поддерживает.

## Возможности

- Задачи, заметки, дата, приоритет и статусы 0/50/100%; создание и редактирование тем.
- **Дублирование:** кнопка ⧉ рядом с задачей или в редакторе. Одна копия на выбранную дату либо копии на весь месяц. Для массового дублирования: Задачи → Выбрать задачи → отметить нужные → На месяц. Можно выбрать дни недели. Перед подтверждением виден точный объём.
- Все копии независимы, их прогресс начинается с 0%. Месячная операция пропускает дату исходной задачи. Повторный запуск намеренно создаёт новые копии; это не правило повторения.
- Рабочие смены и учебные занятия: разовые события и еженедельные повторы, просмотр недели.
- Календарь активности по выполненным задачам, прогресс тем и серия активных дней.
- Вкладка **«Я»**: имя, аватар, рост, заметка о себе; записи по дням с весом, сном, настроением, энергией и стрессом. Каждый показатель необязателен. График за 30 дней, сравнение последних двух заполненных значений и история записей. Запись можно изменить или удалить.
- Восемь тем и четыре шрифта: системный, книжный, Open Sans и моноширинный. Три шрифта поставляются в приложении и доступны офлайн. Их лицензии находятся в `web/fonts/`.
- Анимации переходов между вкладками с выключателем и поддержкой системного уменьшения движения.
- Локальное хранение, экспорт и импорт JSON, работа без интернета.

## Установка и виджеты

**Android 8.0+:** скачайте APK и откройте на телефоне. При необходимости разрешите установку для используемого браузера или файлового менеджера. Это локально подписанная сборка, не публикация в Google Play. Версия 1.1 имеет тот же пакет `ru.planwithme.app`, исходную подпись и больший versionCode, поэтому должна обновлять 1.0 без удаления данных. Резервная копия перед обновлением рекомендуется.

**Виджет Android:** Настройки → Добавить виджет Android. Если лаунчер не поддерживает запрос закрепления, удерживайте пустое место на главном экране → Виджеты → PlanWithMe. Виджет показывает до трёх задач на сегодня, счётчик выполнения и кнопку обновления. Нажатие на задачу открывает её редактор. Данные обновляются при сохранении в приложении, при системном обновлении виджета и по кнопке ↻. Периодические обновления планирует Android: точное время не гарантируется.

**Сайт:** распакуйте `PlanWithMe-web-1.1.zip` на статический HTTPS-хостинг или запустите локально:

```sh
python3 -m http.server --directory web 8000
```

Откройте http://localhost:8000. PWA и офлайн-кэш требуют HTTPS либо localhost. После первого успешного открытия приложение сохраняет свой интерфейс для офлайн-работы. Настройки → На главный экран вызывает установку, если она доступна; иначе следуйте инструкции браузера. На iPhone: Поделиться → На экран Домой. Компактный режим `?widget=1` — отдельное окно сайта с задачами на сегодня, не системный виджет телефона. Если опубликованный сайт ограничен доступом, сначала войдите в разрешённый аккаунт.

## Данные

Android хранит JSON в приватных SharedPreferences приложения; браузер — в localStorage. Профиль и дневник не отправляются на сервер. Виджет выводит только задачи. Удаление приложения, очистка данных или сброс хранилища браузера удаляют локальные записи. Делайте резервные копии в настройках; они содержат и личный дневник.

Дневник показывает введённые пользователем значения, без медицинских выводов. Совместные планы, облачная синхронизация, подписки и фоновые напоминания не реализованы.

## Сборка Android

Нужны JDK 17+, Android SDK Platform 35 и Build Tools 35.0.0, Python 3. Gradle не используется.

```sh
export ANDROID_BUILD_TOOLS=/path/to/sdk/build-tools/35.0.0
export ANDROID_PLATFORM=/path/to/sdk/platforms/android-35/android.jar
export SIGNING_KEY=/secure/path/planwithme-signing.jks
export SIGNING_STORE_PASSWORD=your_password
export SIGNING_KEY_PASSWORD=your_password
bash android/build.sh
python3 scripts/package.py
```

Если javac отсутствует, задайте `ECJ_JAR` с Eclipse Java Compiler 3.39.0. Результат: `android/dist/PlanWithMe.apk`, `releases/android/PlanWithMe-1.1.apk` и совместимая ссылка `dist/PlanWithMe.apk`.

Без SIGNING_KEY скрипт использует `.local/planwithme-signing.jks` и при отсутствии создаёт новый локальный ключ с паролем `android`. Такой ключ **не обновит** APK, подписанный исходным ключом. Исходный ключ первой версии сохранён отдельно в рабочем окружении, в GitHub и исходный ZIP не включён. Не теряйте его для дальнейших обновлений.

## Проверки

```sh
node tests/model.test.js
# В другом терминале: python3 -m http.server --directory web 8000
# Нужны Python playwright и установленный Chromium:
python3 tests/browser_test.py
```

`CHROMIUM_PATH`, `PLANWITHME_URL` и `QA_OUTPUT` позволяют переопределить пути. Проверки покрывают месяцы 28/29/30/31 дней, независимость копий, сброс статуса, миграцию 1.0, профиль, дневник, темы, шрифты, уменьшение движения, узкие экраны, компактный режим и офлайн-PWA. APK собирается и проверяется apksigner; исходная подпись сверяется с 1.0. Реальная установка APK, отображение и закрепление системного виджета на телефоне в этом окружении не проверены.
